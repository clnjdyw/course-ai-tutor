# 自动化 E2E 测试

## 快速开始

### Windows

```bash
# 方式一：双击运行
run-tests.bat

# 方式二：PowerShell
.\run-tests.ps1

# 方式三：npm 命令
npm run test
```

### 单独运行 Playwright

```bash
# 安装依赖
npm install
npx playwright install chromium

# 运行所有测试
npm run test:playwright

# 查看 HTML 报告
npm run test:report
```

## 测试模式

当前测试在 **前端独立模式** 下运行：
- 使用 Mock Token 绕过登录
- 主要验证页面渲染、表单校验、交互逻辑、导航路由
- 需要后端 API 才能测试完整的端到端流程
