# 课程辅导 AI 系统 - 综合测试指南

## 📋 测试概述

本测试系统针对课程辅导AI系统的5大核心功能模块进行全面测试,共包含24个测试用例。

### 测试模块

| 模块 | 测试用例数 | 测试内容 |
|------|-----------|---------|
| 1. 用户中心模块 | 5 | 用户注册登录、个人信息管理、学习目标与学科偏好设置、角色权限区分 |
| 2. 智能问答模块 | 5 | 文字交互、图片交互、语音交互、心理辅导、习题模拟 |
| 3. 知识点管理模块 | 4 | 知识库访问、知识点结构化展示、教师端管理、搜索功能 |
| 4. 个性化学习模块 | 4 | 学习规划生成、进度跟踪、自定义题库、成果统计 |
| 5. 辅助功能模块 | 6 | 笔记、错题收集、数据统计分析、学习提醒、历史记录、成就系统 |

## 🚀 快速开始

### 前置条件

1. 确保已安装 Node.js >= 18
2. 确保已安装 Playwright 浏览器
3. 确保前端和后端服务已启动

### 步骤1: 安装依赖

```bash
# 方式1: 使用批处理文件(推荐)
双击运行: install-xlsx.bat

# 方式2: 手动安装
cd course-ai-tutor-frontend
npm install xlsx
```

### 步骤2: 启动服务

```bash
# 启动后端(在一个终端窗口)
cd course-ai-tutor-backend
npm install
node src/server.js

# 启动前端(在另一个终端窗口)
cd course-ai-tutor-frontend
npm install
npm run dev
```

### 步骤3: 运行测试

```bash
# 方式1: 使用批处理文件(推荐)
双击运行: run-comprehensive-tests.bat
或
双击运行: run-comprehensive-tests.ps1

# 方式2: 使用npm命令
npm run test:comprehensive
npm run test:generate-report

# 方式3: 手动运行
npx playwright test tests/e2e/comprehensive-test.spec.cjs --config=playwright.config.cjs
node tests/generate-excel-report.cjs
```

## 📊 测试结果

测试完成后,将生成以下文件:

### 1. Excel测试报告
**文件位置**: `course-ai-tutor-frontend/test-report.xlsx`

**报告包含5个工作表**:
- **测试总报告**: 所有测试用例的详细结果
- **模块汇总**: 按功能模块统计测试结果
- **测试统计**: 总体测试数据和通过率
- **按模块详细报告**: 每个功能模块的独立测试结果(5个)

**报告内容**:
- 测试用例编号和名称
- 测试内容描述
- 测试结果(通过/失败/部分通过)
- 测试时间
- 截图文件名
- 详细备注

### 2. 测试截图
**目录位置**: `course-ai-tutor-frontend/test-screenshots/`

每个测试用例都会自动截图保存,文件名格式:
- `module{模块}-tc{编号}-{测试名称}.png`
- 失败的测试会有额外的 `-error.png` 截图

### 3. 测试结果JSON
**文件位置**: `course-ai-tutor-frontend/test-results.json`

包含所有测试用例的原始数据,可用于进一步分析。

## 🔧 故障排除

### 问题1: 测试无法连接服务器
**解决方案**:
- 确保后端服务在 `http://localhost:8081` 运行
- 确保前端服务在 `http://localhost:5173` 运行
- 检查防火墙设置

### 问题2: xlsx库未安装
**解决方案**:
```bash
cd course-ai-tutor-frontend
npm install xlsx
```

### 问题3: Playwright浏览器未安装
**解决方案**:
```bash
cd course-ai-tutor-frontend
npx playwright install
```

### 问题4: 测试超时
**解决方案**:
- 检查网络连接
- 检查AI API配置
- 增加超时时间(修改 playwright.config.cjs)
