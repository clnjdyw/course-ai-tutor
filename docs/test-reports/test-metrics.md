## 1. 概述

### 1.1 项目背景

Course-AI-Tutor 是一个面向教育场景的 AI 智能教学平台，包含学习规划、智能教学、实时答疑、学习评估、PK 对战等核心功能模块。项目采用前后端分离架构，前端基于 Vue 3 + Element Plus，后端基于 Express.js + SQLite。

### 1.2 测试目标

| 目标维度 | 说明 |
|---------|------|
| 功能正确性 | 验证所有业务功能按需求规格正常工作 |
| 用户体验 | 确保页面渲染、导航交互流畅无异常 |
| 代码质量 | 通过静态分析发现代码结构问题和潜在缺陷 |
| 回归安全 | 确保新增功能和修复不会引入回归问题 |
| 持续集成 | 建立可自动化的测试流程，支持 CI/CD 流水线 |

### 1.3 测试层级划分

```
        +--------------------------+
        |     E2E 端到端测试        |  <-- Playwright (当前主力)
        +--------------------------+
        |     集成测试              |  <-- API 接口测试 (待补充)
        +--------------------------+
        |     单元测试              |  <-- Vitest/Jest (待补充)
        +--------------------------+
```

## 2. 测试覆盖度指标

### 2.1 代码覆盖度 (Code Coverage)

| 指标名称 | 定义 | 目标值 | 当前状态 |
|---------|------|--------|----------|
| **行覆盖率 (Line Coverage)** | 被测试执行到的代码行数占总代码行数的百分比 | >= 70% | 待测量 |
| **分支覆盖率 (Branch Coverage)** | 被测试执行到的分支数占总分支数的百分比 | >= 60% | 待测量 |
| **函数覆盖率 (Function Coverage)** | 被测试调用到的函数数占总函数数的百分比 | >= 75% | 待测量 |
| **语句覆盖率 (Statement Coverage)** | 被测试执行到的语句数占总语句数的百分比 | >= 70% | 待测量 |

### 2.3 场景覆盖度 (Scenario Coverage)

| 指标名称 | 定义 | 目标值 | 计算公式 |
|---------|------|--------|----------|
| **正向场景覆盖率** | 已覆盖的正常业务流程场景数占全部正向场景数的百分比 | 100% | (已覆盖正向场景数 / 总正向场景数) x 100% |
| **异常场景覆盖率** | 已覆盖的异常/边界场景数占全部异常场景数的百分比 | >= 80% | (已覆盖异常场景数 / 总异常场景数) x 100% |
| **边界场景覆盖率** | 已覆盖的边界条件场景数占全部边界场景数的百分比 | >= 75% | (已覆盖边界场景数 / 总边界场景数) x 100% |

**场景分类清单：**

| 场景类别 | 描述 | 示例 | 覆盖目标 |
|---------|------|------|----------|
| 正向场景 | 用户按正常流程操作 | 正常登录、正常导航、正常提交表单 | 100% |
| 异常场景 | 用户输入非法数据或执行异常操作 | 空表单提交、密码不一致、邮箱格式错误 | >= 80% |
| 边界场景 | 测试数据处于边界条件 | 密码恰好 6 位、超长文本输入、极限分页 | >= 75% |
| 并发场景 | 多用户同时操作 | 多用户同时提交 (待补充) | >= 50% |
| 网络异常场景 | 网络不稳定或断开 | API 超时、断网重连 (待补充) | >= 50% |

## 3. 测试质量指标

### 3.1 通过率指标 (Pass Rate)

| 指标名称 | 定义 | 目标值 | 计算公式 |
|---------|------|--------|----------|
| **用例通过率** | 执行通过的测试用例数占总执行用例数的百分比 | >= 95% | (通过用例数 / 总执行用例数) x 100% |
| **模块通过率** | 某模块下全部通过的用例数占该模块总用例数的百分比 | >= 90% | (模块通过用例数 / 模块总用例数) x 100% |
| **首次通过率** | 首次执行即通过的用例数占总用例数的百分比 (不含重试) | >= 85% | (首次通过用例数 / 总用例数) x 100% |
| **回归通过率** | 回归测试中通过的用例数占回归用例总数的百分比 | >= 98% | (回归通过用例数 / 回归用例总数) x 100% |

**通过率等级定义：**

| 等级 | 通过率范围 | 状态描述 | 处理策略 |
|------|-----------|----------|----------|
| A (优秀) | >= 95% | 质量稳定 | 正常发布 |
| B (良好) | 90% - 94% | 质量可控 | 审查失败用例后发布 |
| C (警戒) | 80% - 89% |
