## 故障排查

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 测试超时 | 服务响应慢 | 增加timeout配置 |
| 元素未找到 | 页面结构变化 | 更新选择器 |
| 登录失败 | 认证问题 | 检查用户凭证 |
| 浏览器未安装 | Playwright未配置 | `npx playwright install` |
